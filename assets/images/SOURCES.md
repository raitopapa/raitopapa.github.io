# Image Source Ledger

画像素材の出典台帳です。自前写真も外部素材も、サイトに使う前にここへ記録します。

## 記入ルール

- 1画像につき1行追加する。
- 自前撮影の場合も `source_url` は `self-shot` と書く。
- 外部素材は、作者名・素材ページURL・ライセンスURL・確認日を必ず残す。
- CC BY / CC BY-SA の場合は、ページ上またはこの台帳で帰属表示できる状態にする。
- 人物・車両・表札・住所・ロゴが写る素材は原則採用しない。

## Approved Source Types

| source | use | conditions |
|---|---|---|
| Self-shot photos | Hero, cards, use cases, blog | 最優先。個人情報・位置情報EXIFを削除 |
| Public agencies | Blog, references, explainers | 出典表記必須。利用規約を個別確認 |
| Wikimedia Commons | Glossary, species/disease explainers | 画像ごとのライセンス確認と帰属表記必須 |
| Unsplash / Pexels / Pixabay | Generic background or temporary visuals | 専門的な診断例には使わない。人物・ブランド写り込み注意 |
